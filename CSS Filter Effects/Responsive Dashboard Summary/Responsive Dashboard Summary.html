Responsive Design Concepts

CSS Filters

CSS filters can change the appearance of images using effects such as blur, grayscale and brightness.

filter: grayscale(100%);

Typography

Responsive typography uses relative units and clamp() to adjust text size on different screens.

font-size: clamp(1rem, 2vw, 1.5rem);

Media Queries

Media queries apply different CSS rules according to the screen size of the device.

@media (max-width: 750px)
