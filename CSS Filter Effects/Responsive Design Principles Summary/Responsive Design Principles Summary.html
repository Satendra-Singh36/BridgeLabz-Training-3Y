Responsive Design Principles

Core principles for creating responsive websites

Fluid Layouts

Fluid layouts use flexible units such as percentages to adjust the layout according to screen size. 

.container {
    width: 90%;
    margin: auto;
}

Flexible Media

Flexible media automatically scales images and videos so they fit properly inside different screen sizes. 

img {
    max-width: 100%;
    height: auto;
}

Breakpoints

Breakpoints use media queries to change the layout according to the device screen width. 

@media (max-width: 600px) {
    .container {
        width: 100%;
    }
}
