Responsive Design

Responsive web design allows a website to adapt to different screen sizes and devices.

CSS Flexbox, Grid, media queries and relative units help create flexible and user-friendly layouts.

CSS Cheat Sheet

Flexbox: Used for one-dimensional layouts.
Grid: Used for rows and columns.
Media Query: Changes styles according to screen size.
Clamp: Creates flexible responsive typography.
