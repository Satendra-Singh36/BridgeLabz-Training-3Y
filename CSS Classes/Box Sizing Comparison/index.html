Understanding content-box and border-box

Default Box

box-sizing: content-box

Width applies only to the content. Padding and border are added to the total size.

Border Box

box-sizing: border-box

Width includes the content, padding and border. The total size remains equal to the given width.

How Box-Sizing Works

With content-box, the specified width applies only to the content area. Padding and border increase the total size.

With border-box, the specified width includes content, padding and border, making sizing easier and more predictable.
