CSS Pseudo-Classes

Examples of Hover, Focus, Active and Nth-Child

:hover

Hover Over Me

The :hover pseudo-class changes the appearance when the mouse pointer is placed over an element.

:focus

The :focus pseudo-class applies styles when an input element receives focus.

:active

The :active pseudo-class applies styles while a button or link is being clicked.

:nth-child()

  • First Item
  • Second Item
  • Third Item
  • Fourth Item

The :nth-child() pseudo-class selects an element based on its position among its siblings.
